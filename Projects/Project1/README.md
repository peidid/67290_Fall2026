## Step 3: Copy and Fill In the Template

1. Make a copy of `Project01-template.html` and rename it with your Andrew ID (e.g., `jdoe.html`).
2. Save your two chart images in the **same folder** as your HTML file, and rename them to short names with no spaces, e.g., `chart-a.png` and `chart-b.png`. In the HTML, type the name exactly, including `.png` or `.jpg`. A broken-image icon means the name doesn't match the file.
3. Open your HTML file in VS Code (installed for Lab 1) or any plain-text editor, and replace every `[REPLACE…]` placeholder and each `IMAGE_FILENAME`:
   - your name and Andrew ID
   - your social issue
   - for each visualization: the image filename, a one-sentence description of the image (alt text), its source, what it shows, the story and whose story, your design critique, and your verdict and one improvement
   - your AI Reflection
4. To preview, double-click your HTML file to open it in your browser, and refresh after each save. (VS Code's "Live Server" also works, but you don't need it.)

> **Mac tip:** don't edit the HTML file in TextEdit's default mode, because it hides the code. Use VS Code instead.

**Prefer Google Docs or Word?** That's fine. Use the same headings as the template and submit a PDF instead (see Step 4).
